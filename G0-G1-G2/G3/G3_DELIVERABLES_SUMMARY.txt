PART 6: KEY FINDINGS & INSIGHTS
================================================================================

1. Binary → Soft Feature Correction
   Problem: G3-0 used Binary Ov/Oi (thresholded) instead of Soft Pv/Pi
   Impact:  +16% average AUPRC improvement
   Lesson:  Preserve probability distributions, avoid premature discretization

2. Signal Hierarchy (by contribution to AUPRC)
   Rank 1: Local Pv/Pi      +0.0908 (70%)  ⭐⭐⭐ PRIMARY
   Rank 2: Neighborhood     +0.0293 (23%)  ⭐⭐   STRONG
   Rank 3: Spatial Position +0.0088 ( 7%)  ⭐    MODERATE
   Rank 4: Temporal Horizon +0.0011 ( 1%)       WEAK

3. Model Performance
   Best:   MLP+H+S+N achieves AUPRC 0.2712 (vs Random 0.1412)
   Gain:   +92% relative improvement
   Gap:    Still 73% below perfect Oracle (room for improvement)

4. Operating Point Trade-off
   Threshold: 0.54 (selected on validation set)
   Recall:    68.5% (captures most beneficial patches)
   Precision: 22.7% (many false accepts)
   Strategy:  Favors opportunity capture over false alarm avoidance

5. Reproducibility
   Level 1: Results verification     100% (bit-exact)
   Level 2: Training repeatability   99.9% (AUPRC ±0.001)
   Level 3: Data reconstruction      99.5% (requires G0 cache)
