七、关键发现与洞察
================================================================================

1. Soft 概率特征至关重要
   - Binary 阈值化丢失 99%+ 的预测信息
   - Soft Pv/Pi 包含关键的细粒度概率分布
   - 设计原则: 保留概率分布，避免过早离散化

2. Local 特征主导预测
   - 70% 的信号来自 4×4 局部 patch
   - Pi-Pv (cooperation gain) 是核心特征
   - |Pi-Pv| (disagreement magnitude) 补充信息

3. Neighborhood 提供显著增益
   - 8 邻居均值统计贡献 23% 增益
   - 空间平滑减少局部噪声
   - 单个 patch 之外的模式具有信息量

4. Temporal 上下文微弱
   - Horizon 编码几乎无效 (+0.001)
   - 合作效用主要是空间的，而非时间的
   - 未来可以考虑移除 Horizon 特征

5. Spatial 位置有适度价值
   - 某些区域系统性地更有益
   - 但 Spatial-only 接近随机
   - 需要与 Local 特征组合才有效

八、与 Oracle 的对比
================================================================================

G2-B Oracle (GT-based):
  - 接受率: 14.9% (17,805 / 119,448)
  - AUPRC: 1.0 (完美)

G3 Learned Predictor (MLP+H+S+N):
  - Test AUPRC: 0.2712
  - Recall@0.54: 68.5% (捕获 68.5% 的有益 patches)
  - Precision@0.54: 22.7% (接受的 patch 中 22.7% 真正有益)
  
性能差距:
  - 相对 Oracle 的 AUPRC 差距: 0.73 (约 73%)
  - 仍有显著改进空间
  - 但已显著优于随机 (92% 提升)

权衡:
  - 当前操作点偏好高 recall (抓住机会)
  - Threshold=0.54 可根据部署需求调整
  - Precision/Recall trade-off 可通过阈值控制
