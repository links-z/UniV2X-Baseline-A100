BUG DESCRIPTION
================================================================================

Severity: BLOCKING
Location: occ_head.py::occ_prob_fusion() lines 843-846

Problem 1: Incorrect Sanity Check
  • Code checked: fused_occ == official_occ
  • Logic error: STCV's purpose is to make them DIFFERENT (selective fusion)
  • Impact: RuntimeError when STCV correctly rejects harmful patches

Problem 2: Mislabeled Output
  • fusion_aux["Oofficial"] pointed to fused_occ (learned)
  • Should point to official_occ (Ov | Oi baseline)
  • Impact: Cannot distinguish Official vs Learned in cache/analysis

================================================================================
ROOT CAUSE
================================================================================

Original UniV2X sanity check assumed:
  fused_occ == official_occ  (always true in non-cooperative mode)

With STCV selective fusion:
  O_learned = O_v ∨ (a_R ∧ O_i)

When STCV rejects patches that change binary output: O_learned ≠ O_official
  → Sanity check fails
  → Blocks G5-1A-2 runtime audit

The check should verify baseline computation (official_occ = Ov | Oi),
not constrain the final output.

================================================================================
FIX APPLIED
================================================================================

1. Corrected Sanity Check Target (4 lines modified)
   Before:
   ```python
   official_check = torch.maximum(veh_occ_log, inf_occ_log)
   if not torch.equal(fused_occ.long(), official_check.long()):
       raise RuntimeError("Official OccFusion != Ov OR Oi")
   ```

   After:
   ```python
   official_check = torch.maximum(veh_occ_log, inf_occ_log)
   if not torch.equal(official_occ.long(), official_check.long()):
       raise RuntimeError("Official OccFusion != Ov OR Oi")
   ```

   Rationale: Check baseline invariant, not final output

2. Fixed fusion_aux Semantics (corrected + added 1 field)
   Before:
   ```python
   "Oofficial": fused_occ.detach(),  # ❌ Wrong
   ```

   After:
   ```python
   "Oofficial": official_occ.detach(),  # ✅ Correct (baseline)
   "Ofused": fused_occ.detach(),        # ✅ New (actual output)
   ```

3. Enhanced Debug Output (2 lines added)
